# Демо без голоса: озвучка моделью

Второй путь записи — самому говорить не нужно. Закадровый текст читает модель
(ElevenLabs, русский), запись экрана делается молча, всё сводится одним скриптом.

## Кто что делает

| Шаг | Кто | Чем |
|---|---|---|
| 1. Текст реплик и тайминги | агент | `scripts/make_narration.py` |
| 2. Запись экрана без голоса | человек | `scripts/record_demo.sh` (только тапаем по боту) |
| 3. Сведение видео + озвучки | агент | `scripts/assemble_demo.py` |

## Шаг 1. Озвучка (уже сделана, 62 секунды речи)

```bash
python3 scripts/make_narration.py --voice Eric      # или George, Matilda, Alice
python3 scripts/make_narration.py --list            # доступные голоса
```

Реплики ложатся в `tmp/narration/01.mp3 … 13.mp3` плюс `plan.json` с таймингами.
Тайминги — ориентир, по ним же надо записывать экран (см. таблицу ниже).

## Шаг 2. Запись экрана молча

```bash
# голос бота пишем цифровым способом — с монитора звуковой карты, без микрофона
MIC=alsa_output.pci-0000_00_1f.3.analog-stereo.monitor bash scripts/record_demo.sh
```

Если пишешь на iPhone — просто выключи микрофон в записи экрана, голос бота
запишется динамиком; качество будет хуже, но для черновика сойдёт.
Лучший вариант для телефона: писать без звука вовсе, а голос бота вставить отдельным файлом.

Что делать по секундам (это важно — по этим моментам ляжет озвучка):

| Момент | Что происходит на экране |
|---|---|
| 0:00 | запись пошла, чат открыт, ничего не нажимаешь |
| 0:25 | отправляешь голосовое №1: «Что с биткоином на четырёхчасовом?» |
| 0:35–0:50 | ждёшь ответ и **даёшь ему прозвучать до конца** |
| 1:40 | голосовое №2: «Покажи дневной график эфира» |
| 1:55–2:15 | ждёшь график и озвучку |
| 2:30 | голосовое №3: «А что по настроению рынка?» |
| 2:45–3:00 | ждёшь ответ |
| 3:05 | стоп (`Ctrl+C` один раз). Кадр держишь до конца закадрового финала |

Проверено симуляцией: при этих моментах все 13 реплик укладываются без наложений,
видео выходит около 3 минут. Меньше 2:40 — три последние фразы обрежутся.

## Шаг 3. Сведение

```bash
python3 scripts/assemble_demo.py \
  --video ~/Videos/voice-market-demo-<дата>.mp4 \
  --subs docs/demo-subtitles-en.srt \
  --out ~/Videos/voice-market-DEMO-final.mp4
```

Скрипт:
- берёт запись экрана и 13 файлов озвучки;
- расставляет реплики по таймингам из `plan.json`;
- микширует с звуком записи (голос бота остаётся слышен, приглушён до 85%);
- при `--subs` вшивает английские субтитры прямо в кадр;
- проверяет, что речь не вылезает за длину видео (предупредит, если вылезла).

Результат — MP4 с H.264 и AAC, готовый к загрузке на YouTube.

## Если рассинхрон

Озвучка привязана к секундам, а не к событиям. Если на записи голосовое ушло
не в 0:36, а в 0:41 — просто сдвинь начало реплик в `tmp/narration/plan.json`
(поле `start`) и пересобери. Одна правка, пересборка занимает секунды.

## Что важно не забыть

- Запись экрана должна быть **без собственного голоса** — иначе он будет спорить с моделью.
- Голос бота лучше писать с монитора звуковой карты, а не микрофоном: тогда в финале
  он звучит чисто, без комнаты и эха.
- Тайминги из таблицы выше — не случайные: под них уже сгенерирована речь.
