# Что говорить в демо (готовый текст для чтения)

> **Озвучиваем по-русски.** Английский вариант ниже оставлен на случай, если захочешь
> попробовать, но для заявки достаточно русского голоса: английские субтитры лежат
> в `docs/demo-subtitles-en.srt` и загружаются в YouTube при публикации.

Темп: обычная речь — примерно 140–150 слов в минуту. Не торопись, после каждого вопроса
держи паузу 2–3 секунды, пока агент отвечает. Текст можно читать с листа — просто держи
взгляд на экране, а не на бумаге.

## Как читать

- **Медленнее, чем кажется нужным.** На записи всегда звучишь быстрее, чем в голове.
- Держи паузу **после вопроса** — агент отвечает 6–12 секунд, это надо заполнить тишиной,
  а не торопливым «ну вот видите».
- Не оправдывайся за ожидание. Ожидание — часть демо: зритель видит, что обработка настоящая.
- Если сбился — не перезаписывай сразу: закончи дубль и реши по результату.
- Одна фраза — одна мысль. Не сливай предложения в длинную тираду.


## Как произносить технические слова (для англоязычной озвучки)

| Написано | Говорим по-русски | Не говорим |
|---|---|---|
| AssemblyAI | *э-СЭМ-бли-эй-ай* | «ассэмбли-аи» в одно слово |
| ElevenLabs | *И-лэ-вэн-лэбс* (без «и») | «элевен лабс» |
| Telegram | *ТЭ-ле-грам* (ударение на первый слог) | «телегра́м» |
| Bollinger Bands | *БО-лин-джер бэндс* | «боллинджер бандс» |
| RSI | по буквам: *ар-эс-ай* | «эрси» |
| API | по буквам: *эй-пи-ай* | «апи» |
| tool calling | *тул ко́-линг* | — |
| code is open source | *коуд из оупен сос* | — |

Общее правило: говори чуть медленнее обычного и делай паузу **на конце каждой фразы**.
Короткие фразы в английском звучат увереннее длинных.
