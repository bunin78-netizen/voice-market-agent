# Сценарий демо-видео (2:30–3:00)

Снимаем одним дублем в Telegram Desktop, окно бота на весь экран, звук с микрофона.
До записи: бот запущен, ключ AssemblyAI жив, BTC/ETH дают данные, окно чата очищено.

| Время | Кадр | Что говорим |
|---|---|---|
| 0:00–0:20 | лицо/аватар бота, пустой чат | «Рыночная сводка обычно требует глаз и рук: терминал, графики, таблицы. Я сделал агента, которому достаточно голоса.» |
| 0:20–0:50 | отправляем голосовое «Что с биткоином на четырёхчасовом?» | «Отправляю голосовое. Telegram отдаёт Opus, ffmpeg приводит к 16 килогерцам, AssemblyAI распознаёт речь и сам определяет язык.» |
| 0:50–1:20 | ответ: текст + голосовое | «Агент вызвал инструменты, получил цену, SMA20, RSI и полосы Боллинджера с публичного API Binance и вернул ответ голосом — слушать можно, не глядя в экран.» |
| 1:20–1:50 | отправляем «Покажи график эфира за день» | «Второй вопрос — уже про картинку. Агент сам решил построить график: свечи, SMA20, полосы Боллинджера и панель RSI.» |
| 1:50–2:15 | приходит PNG, выделяем уровни | «Обратите внимание: модель не спрашивала меня, какой инструмент вызвать — она выбрала его сама по формулировке вопроса.» |
| 2:15–2:40 | отправляем голосом смешанный вопрос «А что по настроению рынка?» | «Индекс страха и жадности — тоже инструмент агента. Ответ снова озвучен.» |
| 2:40–3:00 | финальный кадр: README со схемой | «Стек: AssemblyAI для речи, LLM с tool calling для решений, Telegram как интерфейс. Код открыт, запускается одной командой.» |

## Что обязательно попасть в кадр

- что вопрос задан **голосом**, а не текстом (видно волну голосового сообщения);
- что ответ пришёл **голосом**;
- что график сгенерирован агентом в ответ на просьбу;
- что язык ответа совпадает с языком вопроса (записать второй вопрос по-английски, если хочется показать авто-детект).

## Технические заметки для записи

- Разрешение 1280×720 или выше, шрифт Telegram увеличен на один шаг — цифры должны читаться.
- Перед записью прогреть запрос, чтобы провайдер отвечал быстро; ответ на голосовое — 6–12 секунд.
- Если TTS отвечает дольше 15 секунд, озвучивать только финальный ответ, а не транскрипт.
