# Запись демо на iPhone 14

Вариант для случая, когда проще снять телефоном: iOS пишет экран и микрофон одной кнопкой,
скрипты и ffmpeg не нужны.

## Что важно знать заранее

**Не надевай наушники.** Голос бота идёт из динамика телефона, и микрофон записи ловит
его вместе с твоим голосом. В наушниках речь бота уйдёт в уши и в запись не попадёт —
демо потеряет смысл. Пиши с динамика, телефон держи на расстоянии 30–40 см.

**Только вертикально.** Telegram на iPhone не разворачивается в ландшафт, видео будет 1080×2340.
Для заявки это нормально, но если хочется широкий кадр — снимай на компьютере по `demo-script.md`.

## Подготовка (2 минуты)

1. **Режим «Не беспокоить»** — Центр управления → фокус. Иначе уведомление всплывёт в кадре.
2. **Автоблокировка → Никогда**: Настройки → Экран и яркость → Автоблокировка.
3. **Громкость на максимум** — иначе речь бота в записи будет тихой.
4. **Telegram**: чат с @VoiceMarketAgentBot открыт, старые сообщения не мешают.
   Если хочешь чистый кадр — удали прошлые сообщения или начни с нового чата.
5. **Заряд** — 3 минуты съёмки садят немного, но лучше зарядить.
6. **Место**: 3 минуты в 1080p — примерно 300–450 МБ.

## Запись

1. Центр управления → **кнопка записи экрана** (кружок с точкой).
2. **Долгое нажатие** на неё → включить **«Микрофон»** → «Начать запись».
3. Пять секунд паузы (потом обрежешь).
4. Записываешь дубль по сценарию ниже.
5. Стоп: нажатие на красную полосу времени сверху → «Стоп».
6. Видео попадёт в **Фото → Медиатека** (последнее).

## Сценарий для телефона (портрет, ~2:20)

| Что делаешь | Что говоришь |
|---|---|
| Пауза 3 с, чат с ботом на экране | «Рыночную сводку обычно смотрят глазами: терминал, графики, таблицы. Я сделал агента, которому достаточно голоса.» |
| Голосовое: «Что с биткоином на четырёхчасовом?» | «Отправляю голосовое. AssemblyAI распознаёт речь и сам определяет язык.» |
| Ждёшь ответ | «Агент сам запросил цену, RSI, скользящую среднюю и полосы Боллинджера — и отвечает голосом. Слушать можно, не глядя в экран.» |
| Голосовое: «Покажи график эфира за день» | «Второй вопрос — про картинку. Агент сам решает, что нужен график.» |
| Появился PNG, палец на графике | «Свечи, SMA20, полосы Боллинджера и панель RSI. Модель выбрала инструмент по формулировке вопроса, я его не подсказывал.» |
| Голосовое: «А что по настроению рынка?» | «Индекс страха и жадности — тоже инструмент агента. Ответ снова озвучен.» |
| Финальный кадр: чат целиком | «Стек: AssemblyAI для речи, LLM с вызовом инструментов для решений, Telegram как интерфейс. Код открыт.» |

## Обрезка и публикация

1. **Фото → видео → Изменить** → потянуть ползунки по краям: убрать паузу в начале и хвост.
2. **Поделиться → YouTube** → «Загрузить видео».
3. Видимость: **«Доступ по ссылке»** (unlisted).
4. Название: `Voice Market Agent — voice-first market copilot (demo)`.
5. Описание: вставить черновик из `SUBMISSION.md`.
6. **Субтитры:** в YouTube открой «Субтитры» → «Добавить язык» → English →
   «Загрузить файл» → `docs/demo-subtitles-en.srt`. Тайминги примерные, при необходимости сдвинь по видео.
7. Ссылку прислать в чат — впишем в `SUBMISSION.md`.

## Чего делать не надо

- не снимай через FaceTime/диктофон — качество и синхронизация хуже;
- не добавляй музыку поверх: речь бота станет хуже слышна;
- не пользуйся наушниками (см. первый пункт).
